# システム設計とタスクリスト

## 1. システム概要

**目的:** ローカルのHTMLアーティファクト（UIプロトタイプ）を無限キャンバス上で並べて比較・検討するためのツール。フレームワークに依存せず、独立したHTMLファイルをそのまま表示します。

### アーキテクチャ

*   **ランタイム:** Bun (高速なJSランタイム & バンドラー)
*   **バックエンド:** Bun `Serve` API
    *   静的ファイル配信 (フロントエンドアプリ & アーティファクト)
    *   API: アーティファクト一覧の取得 (`/api/artifacts`)
    *   (オプション) WebSocket: ファイル変更検知とホットリロード
*   **フロントエンド:** Vanilla TypeScript + HTML/CSS
    *   フレームワークレスで軽量に実装
    *   **Canvas UI:** CSS Transform (`scale`, `translate`) を利用した無限キャンバス
    *   **レンダリング:** `<iframe>` を使用して各アーティファクトを隔離・表示

### ディレクトリ構造案

```
/
├── artifacts/       # ユーザーがHTMLファイルを置く場所
├── public/          # フロントエンドの静的ファイル (index.html, styles.css)
├── src/
│   ├── client/      # フロントエンドロジック (canvas.ts, loader.ts)
│   └── server/      # サーバーロジック (index.ts, file-scanner.ts)
├── package.json
└── tsconfig.json
```
